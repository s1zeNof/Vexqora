# Vexqora Trade: глобальний редизайн у стилі OKX (ТЗ для AI-агента)

Референс дизайну (три борди: система, Pulse, сторінка сигналу): https://claude.ai/artifact/4caspcfv2uyhR1ZhxfV7SJ

## 0. Правила роботи

- Змінюється **лише UI**: токени, shell, маршрути, компоненти, сторінки. Бізнес-логіку (executor, risk, адаптери бірж, парсер сигналів) не чіпати.
- Ядро бота не знає, paper чи live. Режим у UI є **лише відображенням** (бейдж, перемикач акаунта). Жодних `if (paper)` у логіці.
- Порядок: токени → shell → Pulse → сторінка сигналу → решта сторінок. Після кожного етапу: typecheck, lint, build, скріншоти 375 / 768 / 1280 / 1920.
- Нічого не вигадуй щодо даних: беремо наявні джерела (Bybit, Supabase, поточні API-роути). Де даних немає, показуй порожній стан, а не заглушку.
- UI-тексти винеси в i18n. Зараз у інтерфейсі змішані англійська й українська (наприклад «Сканувати весь ринок»). Зроби одну мову на локаль.

## 1. Дизайн-принципи (OKX)

Чорна база, плоскі поверхні, тонкі межі, щільні таблиці, великі числа, мінімум декору. Один акцент: **#42F5B9**.

**Заборонено:**
- будь-які градієнти (`linear-gradient`, `radial-gradient`, `conic-gradient`, Tailwind `bg-gradient-*`, `bg-clip-text` з градієнтом), у тому числі на фоні сторінок і кнопках;
- glow, `text-shadow`, `drop-shadow`, декоративний `box-shadow`, `backdrop-blur`, скляні панелі;
- анімовані фони, емодзі в UI (іконки лише SVG, stroke 1.5px, lucide).

**Автоперевірка (має бути порожньо):**
```bash
grep -rEn "gradient|shadow|blur" src --include=*.{ts,tsx,css}
```
Дозволені винятки лише для `focus-visible` outline і системних компонентів бібліотек, і кожен виняток коментується.

## 2. Токени

CSS variables у `globals.css` і мапінг у `tailwind.config`. Хардкод hex у компонентах заборонений.

| Токен | Значення | Використання |
|---|---|---|
| `--bg` | `#000000` | фон сторінки |
| `--surface` | `#111111` | картки, панелі |
| `--raised` | `#1A1A1A` | інпути, таби, hover, вторинні кнопки |
| `--line` | `#262626` | межі 1px, роздільники |
| `--text` | `#FFFFFF` | основний текст |
| `--muted` | `#9A9A9A` | підписи, вторинний текст |
| `--primary` | `#42F5B9` | CTA, long, profit, TP, активний пункт |
| `--on-primary` | `#000000` | текст на primary |
| `--loss` | `#FF5A6E` | short, loss, SL, kill switch |
| `--warn` | `#F5C451` | LIVE-режим, trailing, попередження |

- Тонований фон тегів: колір + 12% альфа (це плоский колір, не градієнт).
- Радіуси: 4 (теги), 8 (кнопки, інпути), 12 (картки). Сітка відступів 4px.
- Шрифт **Inter**, на всіх числах `font-variant-numeric: tabular-nums`. Розміри: 12 (підписи), 14 (текст), 16, 20, 28 (заголовки).
- Колір ніколи не єдиний сигнал: поруч LONG/SHORT, знак `+`/`−`.
- Контраст тексту мінімум 4.5:1, focus ring 2px `--primary`, мінімальна висота кліку 36px (44px на мобільному).

**Компоненти:**
- `Button`: primary (mint, чорний текст), secondary (raised), danger (outline loss). Висота 36 / 44.
- `Tag`: long, short, neutral (PAPER), warn (LIVE).
- `Tabs` (активний: raised-фон, білий текст), `Card`, `Stat` (label 12px + value), `DataTable` (щільні рядки, sticky header), `Input`, `Segmented`, `PriceTag`.

## 3. Глобальний shell

Прибрати лівий sidebar. Верхня навігація 64px, як в OKX.

- Ліворуч: логотип. Пункти: **Pulse, Signals, Positions, History, Settings ▾**. Активний пункт: білий текст + підкреслення 2px primary.
- `Settings ▾` відкриває випадаюче меню під пунктом (як у OKX): Accounts, Risk limits, Integrations, Profile (іконка + назва + один рядок опису).
- Праворуч: пошук пар (іконка, `Cmd/Ctrl+K`), pill режиму з балансом (`Paper · DEMO` або `Live`; клік відкриває вибір акаунта), `Add funds` (лише коли адаптер підтримує `requestDemoFunds`), `Kill switch`, меню профілю.
- LIVE-pill використовує `--warn`, PAPER використовує `--raised`. Це лише візуалізація.
- Мобільна версія: нижня таб-панель (Pulse, Signals, Positions, Settings), бургер для решти.
- KPI-смугу (Equity, Today PnL, Open risk, Win rate) прибрати з усіх сторінок крім Positions, де вона компактна.

## 5. Pulse (картки без води)

**Прибрати:** графік праворуч, великі блоки пояснень («Vexqora Pulse», «Market Activity»), прозу ШІ на картках, кнопки «Scan whole market» та «AI Analysis» як окремі блоки.

**Лишити:** один рядок статусу (кількість пар, біржа, «updated 3s ago») і фільтри (All, Long, Short, Spike, Volume, мінімальна впевненість, сортування).

**Сітка:** 3 колонки на 1280, 2 на планшеті, 1 на мобільному.

**Картка** (жодного тексту довше за один рядок):
1. Рядок 1: символ, тег LONG/SHORT, вік сигналу праворуч.
2. Рядок 2: тригер одним рядком (`Price spike · +2.06% / 10s`).
3. Рядок 3: Entry, Stop loss (loss), TP1 (primary), R:R.
4. Рядок 4: Confidence (число + плоска смуга 4px).
5. Рядок 5: кнопки `Open` (secondary, веде на сторінку сигналу) і `Trade` (primary, існуючий потік preview → confirm).

Усі значення **рахує бекенд** (ШІ-аналіз і скоринг), UI лише показує:
```ts
type PulseSignal = {
  id: string; symbol: string; exchange: 'bybit' | 'binance'; market: 'linear';
  side: 'long' | 'short'; trigger: string;            // один короткий рядок
  entry: number; stopLoss: number; takeProfits: { price: number; sharePct: number }[];
  trailing?: { activationPrice?: number; distancePct: number };
  rr: number; confidence: number;                     // 0..100
  createdAt: string; status: 'active' | 'expired' | 'taken';
};
```
Стани: loading (скелетони без анімованих градієнтів), порожньо, помилка джерела. Оновлення в реальному часі (Realtime або SSE) без перестрибування сітки.

## 6. Сторінка сигналу (як сторінка монети OKX)

Маршрут `/dashboard/signal/[id]`. Layout на 1280: контент 1232px, ліворуч колонка 840px, праворуч 344px, gap 16.

**Шапка:** хлібні крихти, символ, теги `Perp` і біржа, ціна (primary, 28px), зміна за 24h, праворуч Stat-и (24h high, 24h low, 24h volume, funding).

**Ліва колонка:**
- Картка графіка: таймфрейми 1m, 5m, 15m, 1H, 4H, 1D, кнопка Indicators.
- Під графіком таблиця з вкладками **Position, Open orders, History**: символ + плече, сторона, entry, mark, PnL, SL / TP1, дії (`50%`, `Close`).

**Права колонка:**
- Картка сигналу: тригер, entry, SL, TP1–TP3 з частками, trailing, R:R, confidence, вік.
- Панель торгівлі: Market / Limit, доступний баланс, Risk %, Leverage, оцінка ризику, кнопка `Execute signal` (primary). Використовує **той самий** потік, що й чат.

**Графік (переносимо зі сторінки chat, там його прибрати). Накладення:**
- лінії Entry (білий пунктир), SL (loss), TP1…TPn (primary), поточна ціна (суцільна, тег на осі);
- коли є paper або live угода: мітка позиції на лінії входу (`Paper LONG 5x · +176.30 USDT`), маркер входу на свічці, маркери часткових закриттів, лінії оновлюються при перенесенні SL у беззбиток і при активації trailing;
- після закриття: маркер виходу й підсумковий PnL.

**Технічна примітка щодо графіка.** Поточний вбудований TradingView-віджет не дає програмно малювати лінії рівнів. Варіанти (агент має звірити з актуальною документацією):
1. **lightweight-charts** (open-source): `createPriceLine` для рівнів, `setMarkers` для входів/виходів, RSI рахується власним кодом;
2. **TradingView Charting Library** (потрібна ліцензія): `createOrderLine` / `createPositionLine`.

Рекомендація: почати з lightweight-charts. Дані свічок: Bybit kline REST + публічний WebSocket через бекенд. Режим paper/live графік не розрізняє: береться `positions`/`orders`/`trades` активного `account_id`. Вибраний таймфрейм зберігається.

**Стани:** сигнал прострочений (кнопка Execute неактивна, рівні лишаються), угоди немає, позиція відкрита, позиція закрита.

## 7. Сторінка чату

Без графіка. Колонка чату на всю ширину контенту (до 880px по центру) і праворуч компактна картка активної угоди з посиланням `Open chart` на сторінку сигналу. Повідомлення: плоскі поверхні, подієві рядки без декору, поле вводу з кнопками `Form` і `Send`.

## 8. Решта сторінок

- **Positions, History:** щільні таблиці OKX, фільтри-таби, sticky header, експорт (якщо вже є).
- **Settings:** дві колонки (меню секцій зліва, форма справа), Accounts як таблиця з тегом режиму.
- **Risk limits, Integrations:** картки-блоки з перемикачами, без градієнтів і декоративних ілюстрацій.

## 9. Етапи

1. Токени, Tailwind, `Button/Tag/Tabs/Card/DataTable/Stat`, прибрати всі градієнти/тіні/blur (grep чистий).
2. Верхня навігація, mode pill, Settings-меню, мобільна таб-панель, redirects.
3. Pulse: нові картки, фільтри, realtime.
4. Сторінка сигналу: шапка, графік з рівнями, панель сигналу й торгівлі, таблиця позицій.
5. Чат без графіка, Positions, History, Settings.
6. QA.
